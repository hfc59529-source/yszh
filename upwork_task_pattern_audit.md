## Evidence From Clean 20

The useful pattern is not broad "market research" and not a traditional consulting-style "Competitor + Market Opportunity Brief."

The repeated atomic task is:

Research -> Compare -> Synthesize -> Recommend

Common buyer pattern:

- Buyer gives a clear object: competitors, market, brands, channels, speakers, job market, social pages, ads, websites.
- Freelancer collects public facts.
- Freelancer structures comparisons.
- Freelancer identifies differences, gaps, implications, and recommendations.
- Output is usually a report, spreadsheet, slide deck, or brief.

## Working Hypothesis

The current sweet spot appears to be:

- Global or worldwide eligibility
- Fixed-price around $100-$300
- Public information as the main input
- Report / comparison / recommendation as the main output
- Low to medium professional credential barrier

This is a hypothesis for the next scan, not a product decision.
